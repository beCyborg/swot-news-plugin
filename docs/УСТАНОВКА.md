# SWOT News — установка и первый запуск

Плагин для Claude Code, который каждый день превращает мировые новости
в персональный разбор: что из случившегося касается **тебя** и что с этим делать.

Весь путь ниже — минут пятнадцать, из них десять уйдёт на разговор о том,
что тебе интересно.

---

## 1. Что нужно заранее

| Что | Зачем | Как проверить |
|-----|-------|---------------|
| Claude Code | сам плагин | десктопное приложение или `claude` в терминале |
| Python 3.9 или новее | скрипт сбора новостей | в терминале: `python3 --version` (на Windows: `py -3 --version`) |
| Интернет к `news.kagi.com` | источник новостей | — |

Python нужен именно как интерпретатор — никакие пакеты ставить не надо,
скрипт написан на стандартной библиотеке.

Нет Python? Скачай с [python.org/downloads](https://www.python.org/downloads/).
На Windows при установке **обязательно** отметь галочку «Add Python to PATH».

Необязательное, но приятное:
- **Brave Search MCP** — если подключён, плагин будет ежедневно проверять
  выбранные тобой темы свежим веб-поиском. Не подключён — возьмёт встроенный
  поиск Claude Code.
- **Obsidian** — если рабочая папка внутри vault, плагин это заметит сам
  и включит wikilinks, callouts и `.base`-дашборд.

---

## 2. Установка плагина

Открой Claude Code и выполни в чате две команды, по одной:

```
/plugin marketplace add https://github.com/beCyborg/swot-news-plugin
```

```
/plugin install swot-news@swot-news-plugin
```

Первая добавляет источник плагинов, вторая ставит сам плагин.

**Если у тебя десктопное приложение и удобнее меню:** набери `/plugin`
без аргументов — откроется список плагинов, там есть пункты добавления
маркетплейса и установки. Обе дороги ведут в одно место, ядро у CLI
и десктопа общее.

Проверить, что встало:

```
/plugin
```

В списке должен появиться `swot-news`. Если Claude Code предложит
перезапустить сессию — согласись, скиллы подхватываются при старте.

---

## 3. Разрешения

Плагин запускает один Python-скрипт (сбор новостей) и пишет Markdown-файлы
в **одну папку, которую ты выберешь**. Больше он никуда не лезет.

При первом запуске Claude Code спросит разрешение на запуск `python3`.
Можно разрешать каждый раз вручную, а можно один раз разрешить навсегда —
онбординг сам предложит это сделать и объяснит, что именно добавит
в настройки твоего проекта. Отказ ничего не ломает, просто будет чуть больше
кликов.

---

## 4. Первый запуск: онбординг

Перейди в папку, где будут жить новости. Это может быть новая пустая папка,
папка внутри Obsidian-vault или существующая папка с заметками —
плагин заглянет в неё, чтобы понять, чем ты занимаешься.

В чате:

```
/swot-news:setup
```

Что будет дальше:

1. **Осмотр площадки.** Плагин проверит Python, поищет Obsidian, определит
   рабочую папку.
2. **Разбор твоих файлов.** Если в папке есть заметки — прочитает названия
   и несколько профильных файлов, чтобы предположить, чем ты живёшь.
   Покажет гипотезу пятью строчками. Папка пустая — шаг пропустится.
3. **Интервью.** Три коротких набора вопросов с вариантами ответов:
   где живёшь, чем зарабатываешь, что важно в ближайшие месяцы,
   что точно неинтересно, сколько записей хочешь в выпуске.
   Свой вариант можно вписать всегда.
4. **Проход по направлениям Kagi.** Самая содержательная часть.
   Тебе покажут **все** тематические блоки (мир, экономика, технологии,
   Европа, Азия, спорт, локальные ленты…), с пометкой, что рекомендуется
   именно тебе и почему. Внутри выбранных блоков — таблицы конкретных
   категорий. Отвечать номерами: «как предложено», «весь блок 2»,
   «убрать 1.4», «добавить 3.2». Ничего не спрячут: нерекомендованные блоки
   тоже видны, одной строкой.
   Комфортный итог — 25–40 категорий.
5. **Кластеры.** Выбранное разложится по 1–4 группам — по одному аналитику
   на группу. Покажут таблицу, можно пересобрать или перекинуть категорию.
6. **Создание структуры.** Только на этом шаге появятся файлы:
   `Контекст.md`, `SWOT.md`, `_Watchlist.md`, папки квадрантов и `Выпуски/`.
   Прервёшь онбординг раньше — в папке ничего не останется.
7. **Проверка.** Тестовый прогон скрипта и короткий итог.

`Контекст.md` — главный файл настройки. В нём твой профиль, интересы,
неинтересы и приоритеты. Его можно и нужно править руками, когда что-то
изменилось: следующий прогон прочитает новую версию.

---

## 5. Ежедневный запуск

```
/swot-news:daily
```

Батч новостей Kagi выходит примерно в **12:00 UTC** (14:00 в Берлине летом,
7:00 в Нью-Йорке). Запускать имеет смысл через час-другой после этого.

Что произойдёт:

1. Проверка свежести. Батч не новее последнего выпуска — прогон завершится
   одной строкой, файл не создастся. Так и задумано: пустых выпусков не будет.
2. Сбор новостей, параллельный анализ, запись выпуска в `Выпуски/`.
3. Дайджест в чат: топ-дельты, пара фактов для кругозора, открытые вопросы.

**После дайджеста можно просто ответить в чат.** Скажи «эта тема мне
неинтересна» или «расскажи подробнее про второй пункт» — плагин обсудит
и запишет твои предпочтения в `Контекст.md`, чтобы завтра отбирать точнее.

В самом выпуске можно оставлять пометки строками, начинающимися с `> 💬` —
следующий прогон их прочитает и учтёт.

### Расписание

По умолчанию расписания нет — запускаешь руками. Так задумано: сначала
неделю посмотри, нравится ли результат и как ложится время выхода батча.

Захочешь автоматизировать — в Claude Code есть команда `/schedule` для
регулярных запусков; поставь `/swot-news:daily` на время через 1–3 часа
после 12:00 UTC. Скилл к этому готов: он никогда не задаёт блокирующих
вопросов и сам прекращает работу, если свежих новостей нет.

## 6. Если что-то не работает

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| «Конфиг не найден — сначала запусти /swot-news:setup» | `daily` запущен в папке без настройки | перейти в свою рабочую папку либо пройти онбординг |
| «Нужен Python 3.9+» | интерпретатор не найден | установить с python.org; на Windows — галочка «Add Python to PATH»; после установки перезапустить Claude Code |
| «SWOT отложен: батч не новее последнего выпуска» | сегодняшний выпуск уже есть или батч ещё не вышел | это не ошибка; нужен всё равно — `/swot-news:daily --force` |
| Прогон завершился ошибкой про `news.kagi.com` | API недоступен или сменился | повторить через час; не помогло — открыть [issue](https://github.com/beCyborg/swot-news-plugin/issues) |
| Записи не про меня, слишком общие | профиль пустоват | открыть `Контекст.md` и дописать интересы и приоритеты своими словами |
| Слишком много новостей не по теме | взято лишнее на онбординге | `/swot-news:setup --recheck` |
| В выпуске квадратные скобки `[[…]]`, которые не кликаются | включён Obsidian-режим вне Obsidian | в `.swot-news/config.json` поставить `"obsidian": {"enabled": false}` |
| «Из каталога Kagi пропало N категорий» | Kagi убрал категории | `/swot-news:setup --recheck` |
| Claude Code просит разрешение на python каждый раз | allow-list не добавлен | пройти шаг 7 онбординга либо разрешить вручную в настройках проекта |
| Плагина нет в `/plugin` после установки | сессия стартовала раньше установки | перезапустить Claude Code |

### Обновление плагина

Сторонние маркетплейсы сами не обновляются. Когда выйдет новая версия:

```
/plugin marketplace update swot-news-plugin
```

Твои файлы — `Контекст.md`, карточки, выпуски, конфиг — лежат в твоей папке
и обновлением не затрагиваются.

### Удаление

```
/plugin uninstall swot-news@swot-news-plugin
/plugin marketplace remove swot-news-plugin
```

Созданные заметки останутся: это обычные Markdown-файлы, они твои.
