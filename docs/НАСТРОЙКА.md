# SWOT News — справочник настроек

Онбординг (`/swot-news:setup`) создаёт всё сам. Этот документ нужен, когда
хочется поправить что-то руками.

## Где что лежит

```
{рабочая папка}/
├── Контекст.md              профиль — правится руками чаще всего
├── SWOT.md                  оглавление
├── _Watchlist.md            темы-кандидаты
├── Силы/ Слабости/ Возможности/ Угрозы/
├── Выпуски/SWOT_ГГГГ-ММ-ДД.md
├── swot-all.base            только в Obsidian-режиме
└── .swot-news/
    ├── config.json          технические настройки
    └── catalog.json         снимок каталога Kagi с онбординга
```

## Контекст.md — самое важное

Читается целиком каждый прогон. Правь его свободно, структуру не ломай:
заголовки секций используются пайплайном.

| Секция | Что в неё писать |
|--------|------------------|
| **Профиль** | таблица: локация, статусы, занятие, финансы, планы, приоритет №1. Колонка «Как влияет на интерпретацию» — подсказка аналитику, не декорация |
| **Приоритеты** | 1–4 пункта в порядке важности |
| **Интересы** | темы, а не категории Kagi: «спрос на AI-автоматизацию», а не «ai». Поднимают ранг записей |
| **Неинтересы** | уводят темы в «Кругозор» и свёрнутый блок |
| **Мониторить ежедневно** | 0–3 темы, которые обогатитель проверяет свежим веб-поиском. Пусто — обогатитель не запускается, прогон дешевле |
| **Объём** | сколько записей, тон, язык выпусков |
| **Фидбэк-агрегат** | пополняется автоматически по итогам диалогов. Разросся — сожми старое в пару строк |

## config.json — поля

| Поле | Тип | Смысл |
|------|-----|-------|
| `base_dir` | абсолютный путь | корень рабочей папки. Переносишь папку — правь здесь |
| `issues_dir` | строка | подпапка выпусков, по умолчанию `Выпуски` |
| `note_prefix` | строка | префикс имени выпуска, по умолчанию `SWOT_` |
| `timezone` | IANA-имя или `null` | `Europe/Berlin`, `America/New_York`. `null` = системное время |
| `lang` | код языка | язык **батча Kagi**, не выпуска. `en` самый полный — менять без нужды не стоит |
| `batch_hour_utc` | число | час выхода батча по UTC, по умолчанию `12`. Нужен анти-заглушке |
| `entries_budget` | число | максимум записей в выпуске. 5–8 — рабочий диапазон |
| `obsidian.enabled` | `true`/`false` | wikilinks и callouts против обычного Markdown |
| `obsidian.base_file` | `true`/`false` | использовать ли `swot-all.base` |
| `enricher.tool` | `brave` / `websearch` / `off` | чем проверять темы ежедневного мониторинга |
| `context.extra_files` | список путей | дополнительные файлы профиля, читаются каждый прогон. Держи их короткими |
| `clusters` | объект `a`…`d` | зоны ответственности аналитиков: `label` + `categories` |

Пример:

```json
{
  "version": 1,
  "base_dir": "/Users/me/News",
  "issues_dir": "Выпуски",
  "note_prefix": "SWOT_",
  "timezone": "Europe/Berlin",
  "lang": "en",
  "batch_hour_utc": 12,
  "entries_budget": 8,
  "obsidian": { "enabled": true, "base_file": true },
  "enricher": { "tool": "brave" },
  "context": { "extra_files": [] },
  "clusters": {
    "a": { "label": "Мир и геополитика", "categories": ["world", "usa", "china"] },
    "b": { "label": "Технологии и экономика", "categories": ["ai", "tech", "economy"] }
  }
}
```

Кластеров может быть от 1 до 4. Больше кластеров — больше параллельных
аналитиков: быстрее и подробнее, но дороже. Меньше — дешевле.

## Скрипт сбора — режимы

Все команды запускаются из рабочей папки; путь до плагина у тебя будет свой
(его подставляет скилл, вручную звать скрипт обычно не нужно).

| Команда | Что делает |
|---------|-----------|
| `--self-check` | проверка площадки: конфиг, пути, таймзона, доступность API, пропавшие категории |
| `--check-freshness` | вышел ли новый батч |
| `--list-categories --out файл` | живой каталог Kagi, сгруппированный по направлениям |
| `--build-clusters -n 4 --categories "a,b,c"` | разложить категории по кластерам |
| (без флагов) | полный сбор |
| `--config путь` | явный путь к конфигу; то же делает переменная `SWOT_NEWS_CONFIG` |
| `--out-dir путь` | куда класть кластер-файлы; по умолчанию временная папка системы |

Коды выхода: `0` — успех, `1` — ошибка выполнения (JSON с полем `error`
в stdout), `2` — конфиг не найден или нечитаем.

## Типовые правки

**Сменить набор категорий.** `/swot-news:setup --recheck` — пройдёт заново
только выбор категорий и кластеров, `Контекст.md` не тронет.

**Сделать выпуски короче.** `entries_budget` в конфиге или строка «Записи:»
в секции «Объём» Контекста.

**Отключить ежедневное обогащение.** Очистить секцию «Мониторить ежедневно»
в Контексте или поставить `"enricher": {"tool": "off"}`.

**Перенести папку.** Переместить, затем поправить `base_dir` в конфиге
на новый абсолютный путь.

**Переехать в Obsidian.** Положить папку внутрь vault и поставить
`"obsidian": {"enabled": true}`. Уже созданные выпуски останутся в старом
синтаксисе — это нормально, они читаются в обоих режимах.

**Watchlist разросся.** Правило чистки удаляет строки без появлений больше
7 дней и держит не больше 60 строк. Файл всё равно распух — можно смело
удалить старые строки руками, это рабочий буфер, а не архив.

## Что плагин НЕ делает

- Не ходит никуда, кроме `news.kagi.com` (и веб-поиска, если включён обогатитель).
- Не пишет за пределы рабочей папки — кроме временной папки системы,
  куда складываются кластер-файлы на время прогона.
- Не отправляет твой профиль наружу: `Контекст.md` читается локально
  и попадает только в промпты субагентов внутри твоей же сессии.
- Не удаляет карточки: устаревшие получают `status: archived`.
