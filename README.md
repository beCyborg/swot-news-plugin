# SWOT News — плагин для Claude Code

Ежедневный персональный разбор мировых новостей: не «что случилось в мире»,
а **что из случившегося касается лично тебя и что с этим делать**.

Плагин берёт свежий батч [Kagi News](https://news.kagi.com) (публичный API,
ключ не нужен), раскладывает выбранные тобой категории по нескольким
параллельным субагентам-аналитикам, каждый смотрит на новости через призму
твоего профиля — и на выходе получается компактный Markdown-выпуск:
угрозы, возможности, сильные и слабые стороны, с конкретными действиями.

Повторяющиеся сюжеты не пересказываются заново: выпуск дельта-форматный,
устойчивые темы превращаются в карточки, которые живут своей историей.

## Что получится

```
Моя-папка/
├── Контекст.md          профиль, интересы, приоритеты — читается каждый прогон
├── SWOT.md              оглавление базы
├── _Watchlist.md        темы-кандидаты, ещё не ставшие карточками
├── Силы/  Слабости/  Возможности/  Угрозы/     карточки подтверждённых тем
├── Выпуски/
│   └── SWOT_2026-08-09.md
└── .swot-news/config.json
```

## Установка

```
/plugin marketplace add https://github.com/beCyborg/swot-news-plugin
/plugin install swot-news@swot-news-plugin
```

(Короткая форма `beCyborg/swot-news-plugin` тоже работает, но она разворачивается
в SSH-адрес — без настроенного ключа GitHub добавление упадёт. Полный HTTPS-URL
надёжнее.)

Подробно, с картинками процесса и решением проблем — **[docs/УСТАНОВКА.md](docs/УСТАНОВКА.md)**.

## Использование

| Команда | Что делает |
|---------|-----------|
| `/swot-news:setup` | Онбординг: разбор папки, интервью, проход по всем ~165 направлениям Kagi, создание структуры. Один раз |
| `/swot-news:daily` | Ежедневный прогон: сбор → анализ → выпуск → дайджест в чат |
| `/swot-news:setup --recheck` | Пересобрать список категорий (каталог Kagi меняется) |
| `/swot-news:setup --profile` | Поправить только профиль |

Первый запуск — обязательно `setup`: без конфига `daily` печатает одну строку
и ничего не создаёт.

## Требования

- Claude Code (CLI или десктоп).
- **Python 3.9+** — только стандартная библиотека, устанавливать ничего не нужно.
- Интернет: `news.kagi.com`.
- Необязательно: Brave Search MCP — если подключён, ежедневное обогащение тем
  идёт через него, иначе через встроенный веб-поиск.
- Необязательно: Obsidian — плагин определит его сам и включит wikilinks,
  callouts и `.base`-дашборд. Без Obsidian пишет обычный Markdown.

## Как это устроено

1. **Анти-заглушка.** Прогон сверяет `batch_id` свежего батча с последним
   выпуском. Батч не новее — выпуск не создаётся, в чат уходит одна строка.
   Поэтому скилл безопасно вешать на расписание.
2. **Сбор.** `scripts/fetch_kagi_api.py` тянет истории выбранных категорий
   с пагинацией и раскладывает их по 1–4 кластер-файлам во временной папке.
3. **Анализ.** По одному субагенту `analyst` на кластер, параллельно.
   Кластер-файлы весят мегабайты и **никогда** не попадают в основной контекст —
   агенты читают их по путям, точечно.
4. **Синтез и запись.** Дедуп между аналитиками, бюджет записей, выпуск дня,
   обновление карточек и watchlist.
5. **Дайджест.** Топ-дельты и открытые вопросы в чат. Ход завершается сам,
   без блокирующих вопросов.

Настройки — `.swot-news/config.json` в твоей рабочей папке.
Все поля описаны в **[docs/НАСТРОЙКА.md](docs/НАСТРОЙКА.md)**.
