# Шаблон карточки SWOT

Путь: `{база}/{Силы|Слабости|Возможности|Угрозы}/{ID} {Короткое название}.md`
ID: `S|W|O|T-{ГГГГ}-NNN`, где **ГГГГ — год из даты сегодняшнего прогона**
(не зашитая константа), NNN = max существующего номера в квадранте + 1
с ведущими нулями до трёх знаков. Существующие ID не переиспользовать —
проверять `Glob` по папке квадранта, включая карточки прошлых лет.

Соответствие квадрантов: `S` → Силы, `W` → Слабости, `O` → Возможности, `T` → Угрозы.

````markdown
---
type: swot-item
swot_type: {strength | weakness | opportunity | threat}
status: active
impact: {1-5}
likelihood: {1-5}
confidence: {0.1-1.0}
category:
  - {Категория Kagi с большой буквы}
decision: {Мониторить | Мониторить ежедневно | Создать цель | Принять | Пересмотреть план}
created: {YYYY-MM-DD}
last_reviewed: {YYYY-MM-DD}
next_review: {YYYY-MM-DD, created + 30 дней}
---

## Суть

{1–3 предложения с цифрами. Первая строка — самодостаточная: её читают аналитики
как «базу известного», без остального текста карточки.}

## Влияние на меня

{Привязка к профилю: локация, занятие, финансы, планы.}

## Что могу контролировать

- {действие}

## План Б

{Что делать при худшем сценарии.}

## История

- **{YYYY-MM-DD}** — {первое появление / дельта} ([[{note_prefix}{YYYY-MM-DD}]])
````

## Правила

- `priority = impact × likelihood`; пороги: ≥15 🟡, ≥20 🔴.
- Ссылки на выпуски — по `markdown-modes.md` (в plain-режиме относительная ссылка
  `../Выпуски/…`, пробелы как `%20`).
- Архивация: `status: archived` — карточку **не удалять**, она остаётся историей.
- Название файла держать коротким (3–6 слов): оно попадает в каждую ссылку.
- Дополнительные поля frontmatter добавлять можно (их читают только дашборды
  пользователя), но перечисленные выше обязаны присутствовать.
