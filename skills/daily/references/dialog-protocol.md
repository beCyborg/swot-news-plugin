# Дайджест и протокол диалога

## Дайджест (завершение автономного прогона)

Последнее сообщение прогона — компактный дайджест в чат. Язык — по «Языковым
правилам» из `daily-note-template.md`: простой русский, аббревиатуры расшифрованы,
без стрелочных цепочек и алармизма. Только изменившееся — фон не пересказывать.

```
**SWOT {дата} — Chaos {N}/100** → {ссылка на выпуск}

Топ-дельты:
1. {Δ-статус} {запись} — {одна строка простым языком: что случилось и почему важно}
2. …
3. …

🧠 {1–2 факта для кругозора}

Открытые вопросы:
- {Тема X} — обсудить детали?
- {Тема Y} тебе ещё интересна? Третий день без движения.

На сегодня всё.
```

### Строка о деградациях

Если в прогоне что-то отработало не полностью — добавить **одну** строку перед
«На сегодня всё», перечислив через запятую только фактически случившееся:

- `Контекст.md не найден` → «профиль не загружен, запусти /swot-news:setup»;
- обогатитель не запускался или вернул «недоступно» → «обогащение пропущено»;
- `categories_missing` больше 20% списка → «из каталога Kagi пропало {N} категорий,
  стоит перепройти выбор: /swot-news:setup --recheck»;
- аналитик не вернул результат → «кластер {ключ} не проанализирован»;
- `truncated_categories` непустой → «часть историй не догрузилась».

Деградаций не было — строку не писать вообще (пустой отчёт о проблемах — шум).

КРИТИЧНО: ход ЗАВЕРШИТЬ сразу после дайджеста. Никаких блокирующих вопросов
инструментами (`AskUserQuestion` запрещён frontmatter'ом) — иначе автозапуск
завтра не отработает. Вопросы задаются обычным текстом, ответ не ожидается.
Строка «На сегодня всё» — обязательный маркер конца, после неё ничего не добавлять.

## Диалог (если пользователь ответил)

Сессия может остаться живой, и пользователь ответит на дайджест. Тогда:

1. **Обсуждение тем** — раскрыть запись подробнее: данные из выпуска, карточки,
   истории темы. Глубже в источники — только по явной просьбе.
2. **Выяснение интересов** — «интересно/неинтересно», «больше про X, меньше про Y»
   → обновить разделы «Интересы»/«Неинтересы» в `Контекст.md`.
3. **Рассказ фактов** — кругозорные вопросы: ответить, при необходимости дополнить
   поиском.
4. **«Как ответить на угрозу»** — мини-разбор: варианты действий, первый шаг,
   что мониторить → при решении пользователя обновить `decision` и «Влияние на меня»
   соответствующей карточки.

## Итоги диалога

По завершении диалога (пользователь закончил или перевёл тему):
- append в «Фидбэк-агрегат» файла `Контекст.md`:
  `- **{дата}** — {суть: что интересно/неинтересно, решения, мнения}`;
- при изменении приоритетов — обновить «Интересы»/«Мониторить ежедневно» там же;
- при решениях по темам — обновить `decision` и «Влияние на меня» карточек.

Фидбэк-агрегат читается целиком на следующем прогоне и влияет на отбор.
Разросся больше 40 строк — сжать: старые записи свернуть в 2–3 обобщающие строки,
противоречащие свежим — удалить.

## Ручные комментарии в выпуске

Пользователь может дописать в выпуск строки, начинающиеся с `> 💬`. Они
переживают перезапись выпуска и учитываются следующим прогоном
(см. `context-loading.md`).
