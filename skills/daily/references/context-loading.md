# Загрузка живого контекста — порядок и бюджеты

Цель: собрать персональный контекст для анализа, НЕ раздув основной контекст.
Жёсткое правило: читаются только перечисленные файлы и секции, ничего
«на всякий случай». `{база}` = `base_dir` из `.swot-news/config.json`,
`{выпуски}` = `{база}/{issues_dir}` (по умолчанию `Выпуски`).

## Живой контекст (фаза 3 пайплайна)

| # | Источник | Что читать | Бюджет |
|---|----------|-----------|--------|
| 1 | `{база}/Контекст.md` | целиком | ~200 строк |
| 2 | Дополнительные файлы профиля из `context.extra_files` конфига (если заданы) | целиком, если файл ≤150 строк; иначе только первые 100 строк | ≤300 строк суммарно |

Файла нет — пропустить молча, не считать ошибкой.

`Контекст.md` отсутствует целиком → анализ всё равно выполнить, но:
профиль считать пустым, ранжировать по общечеловеческой значимости
и добавить в дайджест строку «Контекст.md не найден — запусти /swot-news:setup».

## База известного (фаза 4 пайплайна)

| # | Источник | Что читать | Бюджет |
|---|----------|-----------|--------|
| 3 | Активные карточки `{база}/{Силы,Слабости,Возможности,Угрозы}/*.md` | frontmatter (`swot_type`, `status`, `impact`, `likelihood`, `decision`, `next_review`) + первая строка после `## Суть` | ~5 строк × N карточек |
| 4 | `{база}/_Watchlist.md` | целиком | ~40 строк |
| 5 | 2 предыдущих выпуска в `{выпуски}` | только заголовки записей (`Grep "^### "`) | ~40 строк |
| 6 | Последний выпуск | строки с `> 💬` (ручные комментарии) + 2 строки контекста выше каждой | по факту |

Карточек больше 40 — брать только `status: active`, отсортированные по
`impact × likelihood` убыв., первые 40; остальные не читать.

`_Watchlist.md` разросся больше 200 строк — это симптом того, что правило чистки
не отрабатывает: прочитать только последние 60 строк таблицы и обязательно
выполнить чистку по `aggregation-rules.md`, п. 2.

## Комментарии `> 💬`

Строки, начинающиеся с `> 💬`, — ручные пометки пользователя в прошлом выпуске.
Их нужно: (а) учесть при анализе как сигнал интереса/неинтереса;
(б) перенести суть в раздел «Фидбэк-агрегат» файла `Контекст.md` с датой;
(в) сохранить как есть при перезаписи того же выпуска (правило идемпотентности).
