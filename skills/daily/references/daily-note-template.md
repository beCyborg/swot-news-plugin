# Шаблон выпуска (дельта-формат)

Путь: `{база}/{issues_dir}/{note_prefix}{YYYY-MM-DD}.md`
(по умолчанию `Выпуски/SWOT_2026-08-09.md`). Язык — русский.
Синтаксис ссылок/callout'ов — по `markdown-modes.md` (ниже показан obsidian-режим).

Три принципа формата:
1. **Дельта**: записи только про НОВОЕ или ИЗМЕНИВШЕЕСЯ; стабильные темы — одной
   строкой ссылкой на карточку. Никаких повторяющихся записей день ото дня.
2. **Finishability**: выпуск конечен — жёсткий бюджет записей, явный маркер конца,
   чтение ≤5 минут. Меньше записей = лучше выпуск.
3. **Layer-cake**: смысл считывается по заголовкам и болд-меткам без чтения тела.
   Информативные заголовки с цифрами, ключевые слова в начале строк.

````markdown
---
type: swot-news-daily
date: {YYYY-MM-DD}
batch_id: {uuid батча из kagi_meta.json}
batch_created_at: {createdAt батча, ISO}
chaos_index: {N}
source_stories: {total_stories}
source_publishers: {total_articles}
---

> [!abstract] TL;DR — Chaos {N}/100 · ~{X} мин чтения
> {Главное новое/изменившееся дня в 1–2 коротких предложениях, простым языком.}
> **Без изменений:** [[T-2026-001 Название|Короткое имя]], [[…|…]] — фон, см. карточки.

## Дельта к [[{note_prefix}{вчерашняя дата}]]

| Запись | Тип | Δ | I×L×C | Горизонт | → Карточка |
|--------|-----|---|-------|----------|-----------|
| {название} | T | эскалация | 4×4×0.8 | Now | [[T-2026-001 …]] |
| {название} | O | новое | 3×3×0.6 | Next | watchlist |

Δ: новое / эскалация / затухание. Горизонт: Now (≤2 нед) / Next (≤3 мес) / Later.
Предыдущего выпуска нет (первый запуск) — заголовок писать «## Обзор дня»
без ссылки, столбец Δ заполнять «новое».

## Записи

**Бюджет выпуска: ≤{entries_budget} записей суммарно** (не на квадрант!). Порядок:
Угрозы, Возможности, Силы, Слабости. Пустой квадрант — пропустить без заглушки.
Каждая запись — каркас «факт → почему важно мне → что делать»
(факты и интерпретация не смешиваются, это разные строки).

### {У1. Информативный заголовок с главной цифрой}

![|420]({primary_image.url})
*Фото: {фото_кредит}*

**Что случилось:** {1–2 предложения фактов с цифрами. Сложной причинной теме —
до 3 предложений контекста, телеграф тут вреден}. [{домен-источник}]({источник_url}) · *{N статей, M доменов}*
**Почему важно мне:** {интерпретация под профиль, человеческим языком}
**Что делать:** {одно конкретное действие — такое, «которое могла бы снять камера»; либо «Мониторить: {что именно и какой триггер}»}
**План Б:** {только для угроз с реальным сценарием ухудшения; иначе строку опустить}
````

## Языковые правила (обязательны и для выпуска, и для дайджеста в чат)

- **Простой русский**: короткие предложения, активный залог. Даже эксперты
  предпочитают plain language — жаргон не сигнализирует компетентность.
- **Аббревиатуры и англицизмы расшифровывать при первом употреблении**:
  «СПГ (сжиженный природный газ)», «ставка ФРС (центробанка США)».
  Названия компаний и продуктов не переводить.
- **Без тикерного жаргона и стрелочных цепочек**: НЕ «Brent ↑3% → RUB ↓ → CPI risk»,
  ДА «Нефть подорожала на 3%, это давит на рубль и разгоняет цены».
- **Нейтрально-предметный тон, без алармизма**: rage-bait и «крючки на страх» —
  отсев ещё на отборе.
- **Факт ≠ интерпретация**: в «Что случилось» — только проверяемые факты с цифрами
  и источником; личное значение и прогнозы — только в «Почему важно мне».
- **Болд — для ключевых слов в начале строк** (скан-якоря), не для украшения.

## Картинки

- Вставлять **только для топ-записей** (наибольший priority / главные дельты),
  **максимум 3–4 картинки на выпуск** — картинка усиливает главное, а не украшает всё.
- Атрибуция обязательна, если `фото_кредит` непустой.
- **Graceful degradation**: нет картинки у истории (Kagi докладывает их в батч
  с задержкой) — запись без картинки, никаких заглушек и placeholder'ов.
- Файлы не скачивать — только внешний embed.

## Правила качества

- **Заголовки записей**: конкретные, с цифрами. НЕ «Ситуация на Ближнем Востоке» →
  ДА «Удары по Рас-Лаффану: 17% мирового СПГ offline на 3–5 лет».
  Заголовок должен работать при скане, без чтения тела.
- **Ссылка на первоисточник в каждой записи обязательна** — пересказ новостей
  моделью искажает факты; ссылка это дешёвый механизм проверки.
  URL берётся из поля `источник_url` кандидата аналитика.
- **Персонализация**: каждая запись обязана иметь «Почему важно мне».
- **Интересы из Контекста** ранжируют записи; неинтересы уходят в Кругозор
  или свёрнутый блок.
- **Время чтения** в TL;DR: ~1 мин на 3 записи + таблицы, округлить до целого.

## Идемпотентность записи

1. Выпуск дня уже существует — прочитать его frontmatter:
   - `batch_id` совпадает с текущим батчем и нет `--force` → НЕ перезаписывать, конец;
   - `batch_id` отличается или отсутствует (стаб/устаревшая версия) → заменить.
2. Перед заменой вычитать из старой версии строки `> 💬` (ручные комментарии)
   и перенести их в новую версию в те же или ближайшие по смыслу секции.
3. Запись — инструментом `Write` целиком (не Edit по кускам): выпуск собирается
   в один проход, частично записанный файл хуже отсутствующего.
